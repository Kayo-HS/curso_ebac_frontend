# Quantum & Code

Portal de notícias desenvolvido com HTML5 e CSS3, focado em conteúdos de tecnologia, inovação e economia.

## 📖 Sobre o projeto

O **Quantum & Code** é um portal de notícias criado como parte dos meus estudos em desenvolvimento web. O objetivo foi aplicar conceitos fundamentais de HTML e CSS, criando uma página organizada, semântica e visualmente agradável.

O projeto apresenta notícias fictícias relacionadas a temas que acompanho e considero relevantes para o mercado atual, como computação quântica, programação, computação em nuvem, transformação digital e energias renováveis.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox

## ✨ Funcionalidades

* Estrutura semântica com HTML5
* Navegação interna entre seções
* Layout organizado com Flexbox
* Estilização personalizada com CSS
* Seções temáticas de Tecnologia e Economia
* Efeitos visuais em botões e links

## 📰 Seções

### Tecnologia

* Computação Quântica
* Java
* Computação em Nuvem

### Economia

* Transformação Digital
* Energia Solar
* Energia Eólica
